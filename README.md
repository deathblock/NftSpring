# NftSpring

NftSpring enables scalable, decentralized NFT management through smart contract execution and auto-scaling blockchain services.

NftSpring is built to be simple and practical, focusing on doing one thing well.

**Why NftSpring?**

- NftSpring enables scalable, decentralized NFT
- management through smart contract execution
- and auto-scaling blockchain services

## Key Features

- NftSpring enables scalable, decentralized NFT
- management through smart contract execution
- and auto-scaling blockchain services

## Technology Stack

- typescript
- typescript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/NftSpring.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure NftSpring, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
